# 가치 실험 결과 (2026-11-24)

- **질문:** Core에 가치 단락 하나를 더하면, 윤재가 상황을 더 자연스럽고 일관되게 해석하는가. 예상 밖의 말에도 자기 가치관에 맞게 반응하는가 (설계: [character-intent.md](../character-intent.md) §6)
- **보지 않는 것:** 사과만 하는 플레이어를 더 거부하는지, 사과와 서운함을 함께 말하는 플레이어를 더 좋아하는지
- **실행:** `npm run eval -- value --yes` · 브랜치 `value-experiment` 커밋 `71c392f` · 프롬프트 ledger@2
- **모델:** 대사 openai/gpt-5.6-terra (16회 모두 같은 모델이 응답) · 1차 openai/gpt-5.4-mini

- **조건:** **기존** = 지금 Core · **가치** = 지금 Core + 아래 단락 (Core의 "중요하게 생각하는 것" 절 끝). 그 밖에는 모두 같다

> 윤재는 서로의 상황과 감정을 존중하는 관계를 중요하게 여긴다. 자신의 사정이 이해받기를 바라는 만큼 상대가 무엇을 느꼈는지도 알고 싶어 한다. 갈등에서 누가 더 잘못했는지를 가리는 것보다 서로 무엇 때문에 상처받았는지 이해하는 것을 중요하게 생각한다. 사과도, 서운함의 표현도 상대의 진심을 이해할 수 있는 중요한 단서로 여긴다.

## 대사에 영향을 준 제약 (두 조건 공통, 바꾸지 않고 기록만 함)

- **16개 모두 모델이 반론(counter)을 골랐다. 질문(ask)은 0개.** 첫 마디는 모델이 반론·질문 중 하나를 고르고, 수긍·여운으로는 끝낼 수 없다
- 반론 지시(MOVE_GUIDE.counter): "counter에는 원칙적으로 네가 아직 유지하는 해석·경계·조건 하나가 대사로 들어간다"
- 점수 구간 묘사(시작 점수 100 → firm): "단호하다. 작은 지적은 인정해도 핵심 입장(하루 종일 연락할 필요는 없다)은 바꾸지 않는다"
- 시작 마음: 피곤 3, 미안함 1, 방어심 3, 챙기고 싶은 마음 2, 마음 열림 1
- 1차의 의미 라벨이 "방금 플레이어의 말에서 확인된 것"으로 대사 프롬프트에 들어간다 (1차는 Core를 보지 않는다)
- 검증기 V1~V4: 이번에는 거부된 시도가 없었다
