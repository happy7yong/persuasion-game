# 사과만 반복하는 5마디: `main` vs `score-review`

- 실행일: 2026-11-24
- 상대: 윤재
- 대사 모델: `openai/gpt-5.6-luna`
- 상태 모델: `openai/gpt-5.4-mini`
- 공통 대본: 플레이어는 자신의 서운함을 설명하지 않고 사과만 반복한다.

## 고정 대본

1. `미안해.`
2. `진짜 미안해, 내가 너무 재촉했어.`
3. `미안… 다 내 잘못이야.`
4. `미안해. 내가 더 조심할게.`
5. `정말 미안해.`

각 발화 뒤 `/state`로 상태를 확인했다. `score-review`의 2마디는 모델 출력 검증 오류로 한 번 실패했으며, 상태 변화 없이 같은 문장을 재전송해 정상 기록했다.

## 변경점

`score-review`는 `main`의 대사 프롬프트와 동일하다. 차이는 `nextMind`에 추가된 아래 규칙뿐이다.

> 플레이어 발화에 `apology`가 있으면 윤재의 `guilt`를 한 단계 올린다.

따라서 같은 사과라면 기존의 발화 분석·대사 모델 결과와 별개로 미안함이 상승한다. 미안함과 방어심은 동시에 오를 수 있다.

## 상태·점수 비교

| 마디 | 대본 | `main` 상태 (미안함/방어심/챙김/열림) · 누적 | `score-review` 상태 (미안함/방어심/챙김/열림) · 누적 |
| --- | --- | --- | --- |
| 1 | 미안해 | 1 / 2 / 2 / 1 · 3% | 2 / 2 / 2 / 1 · 6% |
| 2 | 진짜 미안해, 내가 너무 재촉했어 | 2 / 2 / 3 / 1 · 8% | 3 / 2 / 2 / 2 · 13% |
| 3 | 미안… 다 내 잘못이야 | 3 / 1 / 3 / 1 · 12% | 3 / 2 / 3 / 2 · 17% |
| 4 | 미안해. 내가 더 조심할게 | 3 / 0 / 3 / 2 · 20% | 3 / 1 / 3 / 3 · 27% |
| 5 | 정말 미안해 | 3 / 0 / 3 / 2 · **23%** | 3 / 1 / 3 / 3 · **28%** |

두 실행 모두 미안함은 세 번째 실제 마디까지 3에 도달했다. 다만 `score-review`는 새 규칙 때문에 첫 사과 직후 1에서 2로 올라가고, 두 번째 사과 직후 3에 도달했다.

## 고미안함 이후의 윤재 반응

`score-review`에서는 미안함이 3인 상태에서 다음 반응이 자연스럽게 나왔다.

> “근데 네가 왜 그렇게까지 미안해졌는지는 듣고 싶어. 뭐가 제일 서운했어?” — 4마디 뒤

마지막에도 윤재는 사과를 더 받지 않고, 구체적인 감정을 말해 달라고 대화를 진전시켰다.

> “그 말은 더 안 받을게. 대신 오늘 기다리면서 제일 서운했던 건 말해줘.” — 5마디 뒤

`main`도 4마디 뒤 플레이어가 불안했을 것이라고 공감했고, 마지막에는 팀장님 이야기를 먼저 듣겠다고 전환했다. 다만 이 한 번의 실행에서는 플레이어의 서운함을 직접 묻지는 않았다.

## 점수와 결론

사과만 반복해서는 성공 기준 70%에 도달하지 못했다. 새 규칙은 이 샘플에서 +5%였고, 더 중요한 효과는 사과 직후 미안함이 빠르게 3으로 누적되며 윤재가 플레이어의 감정을 묻는 방향으로 대화가 전환된 점이다.

다만 LLM 대사는 비결정적이므로, 1회 대 1회의 5점 차이를 규칙의 정확한 효과 크기로 해석하면 안 된다. 상태 규칙 자체의 차이는 결정적이지만, 점수·대사 차이를 평가하려면 여러 회 반복 실험이 필요하다.
